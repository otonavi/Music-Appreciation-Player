# Music Appreciation Player

小学校の音楽鑑賞授業向けの、Webブラウザで動く音楽再生・解説アプリケーションです。
先生が提示用のパソコン（プロジェクターや電子黒板）で操作し、児童に見せるためのツールとして設計されています。

## 特徴
- **インストール不要・完全ローカル動作:**
  インターネット接続がなくても、ダウンロードした `index.html` をブラウザ（Google Chrome, Microsoft Edge など）で開くだけで使えます。音声ファイルもパソコン内のものをそのまま読み込みます。
- **楽曲の構造を可視化:**
  「A・B・A'」などの形式を色付きの「区間（セクション）」としてタイムライン上に表示できます。
- **マーカー機能:**
  「ここから主題」「バイオリンに注目」など、特定のタイミングに目印とコメントを付けられます。タイムラインをダブルクリックすると「A点」「B点」と自動で名前が付き、何分何秒に追加されたかも記録されます。クリックですぐにジャンプできます。
- **楽器レイヤー:**
  「どの楽器がどこで鳴っているか」を色分けした帯で視覚的に表現できます。
- **再生速度調整:**
  速い曲をゆっくり再生して楽器の音を聞き取らせたりすることができます。
- **設定の保存と共有（JSON書き出し）:**
  作成した区間やマーカーなどのデータは「JSONファイル」として保存できます。
  **※注意:** 音声ファイル自体は保存されません。他の先生と共有する場合は、このJSONファイルと音声ファイルをセットで渡してください。

## 使い方

1. `index.html` をダブルクリックしてブラウザで開きます。
2. **「音声ファイルを開く」** ボタンを押し、パソコン内にある音楽ファイル（.mp3, .m4a, .wavなど）を選択します。
3. **「編集パネル」** を開き、曲名や作曲者を入力します。
4. 曲を再生しながら、区間やマーカー、レイヤーを設定していきます。
5. 授業の準備ができたら、**「設定をJSONで保存」** を押して設定をダウンロードしておきます。
6. 次回の授業や本番では、同じ音声ファイルを読み込んだ後、保存したJSONファイルを**「JSONを読み込む」**から読み込ませれば、すぐに前回の状態から授業を始められます。

## 動作環境
- Google Chrome, Microsoft Edge, Safari, Firefox の最新バージョン

## 開発情報
- 単一のHTMLファイル (`index.html`) にHTML, CSS, JavaScriptがすべて含まれています。
- スタイルには Tailwind CSS (CDN版) を使用しています。
- アイコンには Lucide (CDN版) を使用しています。
- フォントには Google Fonts (M PLUS Rounded 1c, DM Sans) を使用しています。
